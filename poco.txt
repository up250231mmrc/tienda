========================================

 FLUJO DE TRABAJO EN GIT (4 PERSONAS)

========================================



--- CADA VEZ QUE VAYAS A PROGRAMAR ---



1. ACTUALIZAR TU EQUIPO:

   git checkout main

   git pull origin main



2. CREAR TU RAMA:

   git checkout -b feature/nombre-tarea



3. GUARDAR CAMBIOS:

   git add .

   git commit -m "feat: descripcion corta"



4. SUBIR A GITHUB:

   git push -u origin feature/nombre-tarea



5. EN LA WEB DE GITHUB:

   - Haz clic en "Compare & pull request".

   - Pide revisión a un compañero.

   - Presiona "Squash and merge".



6. REINICIAR LOCALMENTE:

   git checkout main

   git pull origin main
